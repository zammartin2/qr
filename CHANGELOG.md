# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to [Semantic Versioning](https://semver.org/).

## [1.1.0] — 2026-10-08

### Added

- **Browser and edge runtime support** — see [docs/browser.md](docs/browser.md).
- Three entry points with conditional exports:
  - `@fab-orbita/qr` — universal fallback (no `node:*` imports) + environment conditions: `bun`, `workerd`, `edge-light`, `edge-runtime`, `deno`, `browser`, `node`, `default`;
  - `@fab-orbita/qr/node` — synchronous `qrToPNG` (`Buffer`) and real `qrToFile`;
  - `@fab-orbita/qr/browser` — async `qrToPNG` (`Promise<Uint8Array>` via `CompressionStream`) and a descriptive `qrToFile` stub.
- Async PNG renderer for browsers/Workers/Deno (`CompressionStream`, reader-first pattern to avoid backpressure deadlocks; descriptive error when the API is missing, e.g. Vercel Edge Functions).
- Runtime feature detection (`hasCompressionStream`) and shared PNG core (`render/png/shared.ts`) reused by both compressors.
- `render/png/node.ts`: explicit `import { Buffer } from 'node:buffer'` (Deno 2.x does not expose `Buffer` as a global).
- Tests: happy-dom suite for the browser entry, browser-PNG pixel parity against the Node renderer, package-exports shape tests, bundle smoke gate (`npm run test:bundle` — esbuild browser bundling, d.ts contract, condition resolution; **27 checks** total).
- CI: `test:bundle` step plus Bun and Deno smoke jobs.
- `vitest.config.ts`: `src/core/types.ts` excluded from coverage (type-only file, no runtime).

### Changed

- Source layout: shared code moved under `src/core/` (`generateQR` now lives in `core/generate.ts`); `render/png.ts` split into `png/{shared,node,browser}.ts`; `render/index.ts` replaced by `render/file/{node,stub}.ts`.
- Kanji table is now a pure `Uint16Array` literal generated by `scripts/gen-kanji-map.mjs` (no base64, no `Buffer` — required for browsers). Raw bundle grows to ~174 KB, gzip to ~46 KB.
- Build: three-entry tsup config (array), `dist/` cleared by the build script (tsup array configs run concurrently — `clean` would race).
- `docs/` is now included in the published package (error messages link to `docs/browser.md`).
- `scripts/analyze.mjs` is the single size gate (raw/gzip/brotli for every artifact, gzip budget 100 KB).
- `README.md`: added Browser/Edge usage section and exports table.

### Breaking Changes

> **Node.js users are unaffected** — the `node`/`deno`/`bun` conditions resolve `"."` to `index.node` with the synchronous v1.0 contract.

- **`qrToPNG` outside the Node entry is now async** (`Promise<Uint8Array>` instead of `Buffer`). This affects:
  - Universal entry (`@fab-orbita/qr` with `default` condition)
  - Browser entry (`@fab-orbita/qr` with `browser`/`workerd`/`edge-*` conditions)

  For old bundlers that don't read `exports`, use the explicit subpath:

```typescript
import { qrToPNG } from '@fab-orbita/qr/node'; // sync Buffer
```

- **`qrToFile` outside the Node entry now throws** with a pointer to `@fab-orbita/qr/node`. Previously it worked (Node-only). This is intentional: universal/browser builds cannot access `node:fs`.

### Security

- No new runtime dependencies (remains zero-dep).
- Browser entry does not import `node:*` (verified by `test:bundle`).
- `qrToFile` stub prevents accidental file access attempts in browsers.

## [1.0.0] — 2026-10-07

### Added

- Initial release of `@fab-orbita/qr`.
- Full ISO/IEC 18004 symbol generation: versions 1–40, EC levels L/M/Q/H, all 8 mask patterns with N1–N4 penalty scoring and automatic selection.
- Alignment patterns (formula-generated, v32 special case), format information (BCH(15,5)) and version information (BCH(18,6), v7+).
- Encoding modes: numeric, alphanumeric, byte (UTF-8), kanji (Shift JIS via a generated, fully tested Unicode → SJIS table).
- Renderers: terminal (full and half-block), SVG, PNG (zero-dependency hand-rolled encoder), ASCII, plus `qrToFile` for `.svg` / `.png` / `.txt`.
- Public API: `generateQR`, `qrToTerminal`, `qrToSVG`, `qrToPNG`, `qrToASCII`, `qrToFile` with JSDoc on every export.
- Dual ESM/CommonJS build with bundled TypeScript declarations.
- 227 tests, 100% coverage, matrix-level parity against `qrcode@1.5.4` (1280 forced version/EC/mask combinations + auto mode/fuzz corpus).
- CI (Ubuntu/macOS/Windows × Node 18/20/22), publish workflow, bundle-size gate, benchmark script.
- Documentation: README, API reference, examples, compliance notes, performance, migration guides, security policy.
